# Furniture 盈利概况与 Tables 折扣证据边界

## 核心结论

Furniture 样本整体 profit 为 18451.2728，利润率约 2.49%。子品类汇总中 Tables 与 Bookcases 的 profit 均为负，其中 Tables 的利润率最低。

Tables 按折扣率分组后，不同组的 profit 表现存在差异：折扣率为 0.5 的商品交易明细组聚合 profit 为 -8615.3873，折扣率为 0 的商品交易明细组聚合 profit 为 13276.2997。这个结果只能描述历史观察关联，不能据此推算把高折扣取消后能增加多少利润，也不能证明折扣是 Tables 亏损的原因。

## 已核对事实

- Furniture 销售额 741999.7953、profit 18451.2728、利润率约 2.49%、去重订单数 1764。
- Tables 的聚合 profit 为 -17725.4811，利润率约 -8.56%，在四个 Furniture 子品类中利润率最低。
- Bookcases 的聚合 profit 也为负，为 -3472.556；因此 Tables 不是唯一亏损子品类。
- Tables 商品交易明细的平均折扣率约 26.13%，最高折扣率为 50%。这两个数字本身不能证明折扣偏高。

## 下一步分析建议

1. 按 SKU、地区和时间拆分 Tables 的折扣、销售额与 profit，检查商品组合和样本结构。
2. 由业务和财务负责人确认 profit 的成本口径，并核查异常商品交易明细。
3. 如果业务确实需要估计折扣的增量效果，应先定义指标与风险边界，再采用随机试验或可信准实验。
4. 如需客户画像、复购或留存分析，应先补充经过合规处理的稳定 customer_id 和相应行为数据。

## 限制

- 数据是一条商品交易明细，而不是一张订单一行；同一订单可能包含多条明细。
- profit 的完整业务成本口径尚未核对，不能直接改用更具体的会计利润术语。
- 当前没有取消折扣的反事实或随机对照，不能估算取消折扣后的利润增量。
- 分组汇总只能说明历史关联，不能确认亏损原因。

本示例不触发任何折扣调整；是否采取后续动作必须由人工业务负责人决定。
