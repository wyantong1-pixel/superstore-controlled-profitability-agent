# 08 离线 Evaluation 评测集

本评测集将真实运行中发现的报告失败固定为可重复离线案例。它只评估本地报告契约和验证器，不调用LLM，不衡量模型总体准确率。

## 运行

```powershell
.\.venv\Scripts\python.exe scripts\run_evals.py
```

## 边界

- 评测通过表示固定的已知错误能被验证器拦截，不代表LLM能稳定生成合格报告。
- 结构化字段不能保证自由文本的真实含义与申报一致，仍需人工语义审核。
- 未来在线模型评测应另行记录模型版本、费用、耗时、重复次数和人工判分，不与本地验证器评测混为一个“准确率”。
