## 当前验证边界

已在本机 Python 3.13.14、Pandas 3.0.6 环境执行数据检查、自动测试、离线演示与受控在线验收。单元测试使用独立4行手算样本，覆盖数据门禁、查询权限与限制、证据校验、停止状态、日志脱敏及模拟HTTP异常。

真实数据的离线演示完成，状态为`awaiting_human_review`；此状态不是已有人批准。离线报告显式注明固定脚本模拟，不是LLM能力结果。

首次测试捕获并修复：

1. SQLite对整数金额执行整数除法，利润率被截断：金额与折扣列入库强制REAL，保留小样本回归。
2. SQLite COUNT(*)授权回调的数据库名可能为None：仅允许orders空列的特定读取，不放开其他表或写权限。

真实百炼账号连通性和 `qwen-plus` 工具调用已经验证。完成了 Furniture 基础运行、证据不足问题复验和 Office Supplies 换对象验收；在线原报告均经过人工语义审核，修订稿分别形成独立接受记录。原始运行目录包含完整审计信息，默认由 `.gitignore` 排除，不随公开仓库上传。

**尚未验证：**真实费用金额和多次重复运行的长期稳定性。费用应以模型平台账单为准；当前少量在线案例不能用于估计总体准确率或稳定性。模拟HTTP测试仍只证明异常处理逻辑，不等于线上模型质量。

详尽的最终本地与在线测试结果见同目录 `06_交付测试结果.md`。历史离线结果和后续在线运行分别记录，没有跨运行拼接或覆盖原始报告。
