## 测试覆盖

- 缺字段、重复明细、无效数值/日期、折扣越界、空数据、零分母、无关个人字段移除。
- 合法SUM、COUNT(*)、CTE；拒绝写入/系统表/扩展/多语句/递归；资源上限、结果截断、重复别名。
- 固定模拟器端到端、数据失败零模型调用、轮数/工具/上下文限制、非法JSON、普通文本不能代替提交。
- 错误核心数值、伪造证据、截断证据拒绝；本地参考答案不放入模型上下文；模拟密钥脱敏。
- 模拟HTTP请求结构与usage、401不重试、429只重试一次、直接超时与网络异常包装的超时均不重试、其他连接错误可区分、截断或非法JSON响应拒绝。

## 开发中发现并修复

1. 整数金额在SQLite里触发整数除法：明确REAL类型。
2. COUNT(*)特殊授权回调被误拒绝：针对orders空列读取放行。
3. 离线模拟交互次数不应计为真实API请求：分别记录provider_requests与api_requests，demo真实API请求数为0。
4. 真实报告引用了正确折扣组标签，却把该组错误称为“亏损最严重”：排名主张现必须声明数值列和 min/max 方向，程序用整个未截断结果集复算。
5. 单行 SQL `MIN/MAX` 已直接得到极值时不属于返回行间排名：现在可用该聚合单元格直接证明，避免误要求 `comparison`。
6. 报告声明没有估计因果效应却在自由文本给出精确货币收益：现在摘要、假设和行动中的此类预测会被拒绝。

旧开发运行目录可能保留修复前的元数据，属于开发历史；以最终源码重新运行的新目录为准。所有目录都有源码哈希，不能跨版本拼接当同一次运行。
